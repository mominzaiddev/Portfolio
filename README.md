# 👨‍💻 Momin Zaid | Personal Portfolio

A modern, responsive personal portfolio website showcasing my skills, projects and contact details as an aspiring **Full Stack Developer**.

🔗 **Live Demo:** https://mominzaid-portfolio.netlify.app/

## ✨ Features

- Clean, responsive design for mobile, tablet and desktop
- Smooth single-page navigation: Home, About, Skills, Projects, Contact
- Animated hero section with a developer code card
- Skills grouped into Frontend, Database, Troubleshooting and Tools
- Selected projects with live demo and GitHub links
- Quick contact options: Email, Call, LinkedIn and GitHub
- Scroll reveal animations
